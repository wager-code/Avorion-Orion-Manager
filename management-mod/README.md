# OrionAdminBridge 0.10.0

此包保留完整专用 MOD Lua 源码。入口 `data/scripts/commands/orionadmin.lua` 仅负责控制台鉴权和调用固定分派器；协议、玩家、玩家资产、玩家奖励、邮件奖励、联盟、联盟资产、Inventory、星区和动作分派分别位于 `data/scripts/lib/orionadmin/` 的独立模块。
Avorion 2.5.13，serverSideOnly=true、saveGameAltering=true，无后台轮询或玩家/实体驻留脚本。当前能力包括只读 hello、在线/已知玩家身份、玩家及联盟 Credits、七种资源和 Inventory、联盟列表与成员、已加载星区，以及玩家/联盟白名单系统插件发放、单人/联盟资产奖励、唯一游戏内邮件投递和尝试卸载一个当前无在线玩家的已加载星区。
本机 RCON 发起命令，后端验证响应协议、组件版本与请求关联；游戏玩家 sender 非 nil 时拒绝。普通 Steam 客户端无须安装组件的接入、真实玩家位置/退出传播、联盟读取、玩家与联盟奖励、Inventory 读取、玩家/联盟各一次系统插件发放、唯一 Mail ID/附件复核、占用星区拒绝及随后空星区卸载均已在正式本机服务器验证。

旧机硬编码路径的一次性安装/备份脚本未收录，它们不是软件功能；当前可追溯证据保存在 `docs/evidence/`、根目录能力矩阵与 Git 历史中。
新电脑请根据实际安装路径，在已停止的隔离 Galaxy 中按官方格式启用包，保留其他 MOD 配置。不要覆盖原版命令脚本。
配置向导现可明确选择安装或升级随包组件；Server Agent 在停服状态原子发布并保留旧版本备份，更新页显示随包/已安装版本、启用状态和真实 hello 连接。现有 modconfig.lua 不会被自动覆盖。

后续增加奖励、物资、船员、舰船、空间站或事件能力时，不得把实现继续追加到命令入口。每个领域新增单独 lib 模块，只由入口登记动作；写操作继续要求固定动作白名单、严格参数上限、RCON/控制台来源和后端审计。
