# 游戏活动中心

> 当前产品边界（2026-09-07）：用户已确认专用管理 MOD；本文活动方案属于后续阶段，尚未实现。M1 只做握手与在线玩家读取，Callback 和游戏写操作逐项验证后才开放；不使用 Mock 数据代替未实现能力。

## 目标
让管理员通过 Web 页面主动创建 Avorion 服务器活动，而不是进入游戏手工操作。

## V1 模板

### 海盗袭击
- 目标：玩家 / 联盟 / 指定星区
- 强度
- 舰船数量
- 波次数
- 开始前广播
- 完成奖励

基础 API：
- `Galaxy.getPirateFaction(level)`
- `Sector.createShip(...)`
- `ShipAI.registerEnemyFaction(...)`
- `ShipAI.setAggressive(...)`
- `ShipAI.setAttack(...)`

### 敌对派系袭击
- 使用 Local/Nearest Faction 或明确选定 faction
- 本次生成舰船针对目标注册敌对关系
- 不要未经用户允许永久修改整个银河的外交关系

### 波次防御
- N 波
- 每波舰船数/模板
- 全部消灭再进入下一波
- 最终奖励

### 悬赏目标
- 生成特殊目标船
- 显示目标星区
- 击毁后发奖励

## UI
推荐：
左侧活动配置 + 右侧完整预览/确认。
最终点击“启动活动”前展示：目标、星区、舰船数量、波次、奖励、广播内容。
