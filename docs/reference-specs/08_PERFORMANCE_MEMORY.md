# 性能、内存与星区规划

用户实际痛点：Avorion 服务端运行时间越久，RAM 越高。

## 第一版要做
- RAM 当前值
- 启动基线
- 1h / 24h / 7d 趋势
- 增长速度
- 阈值告警
- CPU / 网络 / 磁盘 / 玩家数同步展示

## 官方 API
`Galaxy [Server].tryUnloadSector(x, y)` 已确认。

内存与星区页面可提供：
- 加载星区概览
- 有玩家星区
- 可尝试卸载的空闲星区（Agent/MOD 按安全规则筛选）
- “安全尝试卸载空闲星区”按钮

禁止：
- 宣传“强制释放全部内存”
- 伪造清理效果
- 把 `collectgarbage()` 当成整个 Avorion 服务端的 RAM 优化按钮

## 自动策略
默认只告警，不默认自动重启。
管理员可以显式选择：
- 仅提醒
- 尝试安全卸载空闲星区
- 达到严重阈值后执行安全保存+重启（默认关闭）
