# 用户要求的长期软件开发流程

这是强制原则。

```text
需求沟通
  ↓
功能调查 / 能力验证
  ↓
产品功能规划
  ↓
页面信息架构
  ↓
UX 线框
  ↓
高保真 UI / Design System
  ↓
用户确认
  ↓
正式开发
  ↓
实际运行
  ↓
截图视觉 QA
  ↓
修正
  ↓
功能测试 / 交付
```

## Codex 沟通原则
用户不需要学代码。

Codex：
- 主动发现功能遗漏
- 主动解释重要产品取舍
- 不要求用户理解技术细节才能继续
- 给用户看可见成果
- 遇到 UI 问题必须运行后“看”界面再改
- 不准只说“已优化 UI”却没有实际渲染检查

## UI 修改闭环

```text
实现 UI
 → 运行
 → 浏览器截图
 → 对照母版/设计规范
 → 检查间距/配色/层级/中文/响应式
 → 修改
 → 再截图
```

“能运行”不是 UI 完成标准。
